# Changelog

## 1.2 – 2026-10-12
- First version under the name **RetroCal** (bundle ID `com.retromac.retrocal`)
- Day, week, month and year views (year with heatmap and week numbers), sidebar, page-turn swipe animation
- Local calendars and system calendars (EventKit): read, edit, rename, recolor, delete
- Recurring events, move and resize with the mouse, undo/redo
- Search with suggestions, quick event with natural-language input (English/German)
- iCalendar import and export
- Own textures generated from random noise (`Reference/gen_assets.py`), own icon
- *Settings › General › App icon*: custom PNG (exactly 256 × 256 pixels) as Dock icon
- Repository unified with RetroNotes and RetroReminder: GPL-3.0 license, English documentation, common layout
